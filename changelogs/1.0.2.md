# MarkItDown Drop 1.0.2

Veröffentlicht am 16. August 2026.

## Automatische Updates

- Automatische Updateprüfung mit Sparkle ergänzt
- Einstellungen für automatische Downloads und Installationen hinzugefügt
- Universelle App für Apple Silicon und Intel erstellt
- Updates mit einer kostenlosen EdDSA-Signatur abgesichert
- Ersteinrichtung für Homebrew, Python und Microsoft MarkItDown beibehalten

Dies ist die erste Version mit eingebauter Updatefunktion. Sie musste einmal manuell installiert werden; spätere Versionen können direkt über die App aktualisiert werden.
