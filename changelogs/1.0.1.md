# MarkItDown Drop 1.0.1

Erste dokumentierte App-Version vom 16. August 2026. Diese Version wurde nicht als öffentliches GitHub-Release verteilt.

## Grundfunktionen

- Native macOS-App mit Drag-and-drop und Dateiauswahl
- Lokale Konvertierung über Microsoft MarkItDown
- macOS-Speicherdialog für erzeugte Markdown-Dateien
- Statusanzeige während der Konvertierung

## Ersteinrichtung

- Homebrew automatisch prüfen und bei Bedarf installieren
- Python 3 und Git installieren
- Microsoft MarkItDown direkt aus dem offiziellen GitHub-Repository laden
- Isolierte Python-Umgebung im Application-Support-Ordner anlegen

## Oberfläche

- Helle und dunkle Darstellung
- Eigenes App-, Finder- und Dock-Icon
- Über-Dialog mit Autor Kevin Stegmiller

Die öffentliche Release- und Update-Historie beginnt mit Version 1.0.2.
